ACTIVATE BADGE TRACKER v7.2 — FOCUS MODE FIX

Focus Mode now:
- Choose a room.
- Shows only badges for that room at the current venue.
- Unearned badges are shown by default.
- Optional toggle shows earned badges too.
- Nothing is auto-selected.
- You choose which badges to pin.
- Maximum 5 pinned badges total across any rooms.
- Focus route only uses badges you selected.

UPLOAD
1. Unzip this package.
2. GitHub > Activate-badge-tracker > Code > Add file > Upload files.
3. Upload ALL files inside to the repository root.
4. Commit directly to main.
5. Wait 1-3 minutes for GitHub Pages to redeploy.
6. Refresh/reopen the app.

You do NOT need to empty the repository first.
