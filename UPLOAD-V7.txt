ACTIVATE BADGE TRACKER v7 — VENUE EDITOR + MANUAL FOCUS

WHAT CHANGED
- Venue Editor
  - Entrance is always the start point, facing forward.
  - Exit is always available as a location.
  - Set how many copies of each room exist.
  - The app creates Laser 1, Laser 2, Strike 1, Strike 2, etc.
  - For each room instance, set Front / Left / Right / Back connections.
  - Left and Right are intended for alcoves, side corridors, and turns.
- Focus setup
  - No automatic pin selection.
  - Pick a room and choose the applicable badges yourself.
  - Maximum 5 pinned badges total across any rooms.
  - Focus remains optional.
- Route
  - Uses the venue connections when available.
  - Groups pins by room and tries to choose a nearby room instance.

WHAT TO UPLOAD
Upload ALL files from this ZIP to the ROOT of your existing GitHub repository.
Do NOT delete the repository first.

Most important files that must replace the old ones:
- index.html
- sw.js
- manifest.webmanifest
- icon-192.png
- icon-512.png
- icon-maskable-512.png
- splash-portrait.png
- splash-landscape.png

HOW
1. Unzip the package.
2. GitHub > Activate-badge-tracker > Code.
3. Add file > Upload files.
4. Select every file inside the unzipped package.
5. Commit directly to main.
6. Wait 1-3 minutes for GitHub Pages.
7. Refresh the app. If the installed PWA still behaves like the old version, fully close it and reopen it. If needed, uninstall/reinstall the home-screen app.

BACKUP
Export a backup in Settings before updating if you have already entered important progress.
