ACTIVATE BADGE TRACKER — v6

Galaxy Fold-oriented personal PWA / standalone app.

WHAT'S NEW IN v6
- Proper 192px and 512px Android app icons
- Trophy/badge completion celebration overlay
- Auto recommendations for available, unearned badges
- Manual room walking order per saved location
- Room-grouped session route using that order
- Improved Fold portrait/landscape polish
- v5/v4/v3 browser-state migration
- Same one-tap Complete & Next Focus workflow
- Same optional location/date/player achievement records
- Same search, favourites, notes, stats, backup/restore and offline support

IMPORTANT ABOUT ROUTING
The app does NOT know the physical floor plan of an Activate venue. You set the room walking order once in Locations; the Session route then groups pinned badges into that order.

FASTEST USE
Open Activate-Badge-Tracker-Standalone-v6.html directly in a browser.

TRUE HOME-SCREEN APP
Host the folder contents on any HTTPS host (GitHub Pages works), open the URL on your Galaxy Fold in Samsung Internet or Chrome, then choose Install app / Add to Home screen.
The included manifest supplies the icon, and the service worker caches the app for offline use after first load.
