ACTIVATE BADGE TRACKER v6.1 — COMPLETE GITHUB UPLOAD

This folder is the complete integrated app. It includes the app code plus the neon icons and splash screens.

UPLOAD:
1. Unzip this package.
2. Open GitHub > djsmartyp/Activate-badge-tracker > Code.
3. Choose Add file > Upload files.
4. Upload ALL files inside this folder to the ROOT of the repository.
5. Allow same-named files to replace/update the existing versions.
6. Commit directly to main.
7. Wait 1–3 minutes for GitHub Pages to redeploy.
8. Open your Pages site and refresh.
9. If Android shows an old cached icon, remove the installed home-screen app and reinstall it.

IMPORTANT:
Do not upload this ZIP itself as the website content.
Upload the files INSIDE it.

The app stores progress locally in the browser/PWA storage. Export a backup from Settings before major changes if you have already entered important progress.
