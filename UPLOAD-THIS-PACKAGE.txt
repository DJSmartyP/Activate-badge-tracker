GITHUB — FROM AN EMPTY REPOSITORY
1. Open djsmartyp/Activate-badge-tracker.
2. Choose Add file > Upload files.
3. Unzip this package on your device first.
4. Upload ALL files inside the unzipped folder.
5. Do not upload only the ZIP.
6. Commit directly to main.
7. Open Settings > Pages.
8. Source: Deploy from a branch.
9. Branch: main.
10. Folder: / (root).
11. Save.
12. Wait 1–3 minutes.
13. Open:
   https://djsmartyp.github.io/Activate-badge-tracker/
14. Test the buttons in the browser before installing.
15. Then choose Install app / Add to Home screen.

IMPORTANT
This clean v8 build uses separate JSON files. It is designed to run from GitHub Pages over HTTPS.
The repository may be otherwise empty: no other files are required.
